1. 수업 먼저 생성하기

현재 제공되는 Native API는 강의 등록·수정 API입니다. 수업 자체를 생성하는 API는 구현되어 있지 않습니다.

관리자 → 수업 관리 → 새 수업에서 수업 코드(예: AI101)와 수업명, 주차 수를 등록한 다음, 아래 요청에 수업 코드를 사용합니다.

2. API 인증

API · 기본 설정의 전역 토큰이나 수업 운영 화면에서 발급한 수업 전용 토큰을 사용합니다.

POST /?module=simple_video_learning&act=procSimple_video_learningApiUpsertLecture

HTTPS 환경에서 HTTP Authorization: Bearer YOUR_TOKEN 헤더를 전달합니다. 수업 전용 토큰은 발급된 수업에만 사용할 수 있습니다.

3. 강의 등록 요청

이미 존재하는 course_code를 지정하면 원하는 주차에 영상을 등록합니다. 같은 external_id를 다시 보내면 기존 강의를 갱신합니다.

curl -X POST 'https://YOUR-DOMAIN/?module=simple_video_learning&act=procSimple_video_learningApiUpsertLecture' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "external_id": "cloud-lecture-03",
    "course_code": "AI101",
    "sectionnum": 3,
    "sort_order": 1,
    "title": "클라우드 개요",
    "content": "3주차 강의입니다.",
    "video_url": "https://cdn.example.com/cloud-week3.mp4",
    "duration": 900,
    "completion_threshold": 80
  }'

필수: external_id, title, video_url 및 수업 식별자(course_code 또는 course_srl). video_url은 HTTP(S) URL이어야 합니다. sectionnum 기본값은 1입니다. URL은 서버로 영상을 직접 업로드하는 방식이 아니라 영상 주소를 등록하는 방식입니다.

4. 등록 결과 확인

성공하면 문서 번호와 강의 화면 주소가 반환됩니다.

{
  "success": true,
  "external_id": "cloud-lecture-03",
  "platform_id": 12345,
  "document_srl": 12345,
  "url": "https://YOUR-DOMAIN/...",
  "created": true
}

위 응답은 필드 구조를 보여주는 예시입니다. 실제 번호·URL은 요청에 따라 달라집니다. 조회는 GET /?module=simple_video_learning&act=dispSimple_video_learningApiLecture&external_id=cloud-lecture-03 및 동일한 Bearer 토큰을 사용합니다.

5. Moodle 호환 연동

기존 Moodle 방식 클라이언트를 위한 별도 호환 인터페이스입니다.

/modules/simple_video_learning/compat

지원 함수: core_enrol_get_users_courses, core_course_get_contents, mod_simplevideotracker_create_activity, mod_simplevideotracker_set_video 등.

활동 생성 시 courseid 및 sectionnum(또는 week_no, week, section)으로 수업과 주차를 지정합니다. sectionnum=3이면 3주차에 강의를 배정합니다. 영상 파일 전송은 별도의 호환 업로드 엔드포인트를 이용합니다.

오류 확인

401Bearer 토큰 누락 또는 인증 실패
403수업 전용 토큰으로 다른 수업 접근
422필수 입력 누락·유효하지 않은 수업 코드·영상 URL
503강의를 저장할 이러닝 메뉴를 찾지 못함
